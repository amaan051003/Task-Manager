# Task Management System

A full-stack Task Management System developed as a Minor Project by a team of B.Tech students. The application helps organizations and teams efficiently manage tasks, monitor progress, collaborate with team members, and streamline workflow management.

## 📌 Project Overview

This project provides a centralized platform where managers can create teams, assign tasks, monitor progress, and track employee performance. Employees can view assigned tasks, update progress, upload submissions, and receive notifications.

## 🚀 Features

### Authentication & Authorization

* Secure JWT-based authentication
* Login and registration system
* Role-based access control
* Manager and Employee dashboards

### Team Management

* Create and manage teams
* Add or remove team members
* Monitor team performance

### Task Management

* Create, assign, update, and delete tasks
* Assign tasks to employees or teams
* Set priorities and deadlines
* Track task progress and status
* Upload task-related files and attachments

### Notifications

* Real-time notification support
* Mark notifications as read
* Notification tracking system

### Dashboard

* Task statistics
* Progress monitoring
* Team overview
* Performance tracking

## ⚙️ Installation

### Clone Repository

```bash
git clone <repository-url>
cd task-management-system
```

### Backend Setup

```bash
cd backend
npm install
npm run dev
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
